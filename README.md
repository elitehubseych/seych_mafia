# 🎭 Бот Мафия (ВКонтакте)

Бот для игры в мафию по правилам из `rules_mafia.txt`. Python + `aiohttp` (VK **Callback API**).

## Возможности

- Регистрация через `/start` в беседе, кнопка «Присоединиться», лимит 15 игроков, таймер 5 минут, автостарт при заполнении.
- `/setnick Ник` — никнейм; `/startadmin` — принудительный старт (админ); `/stopadmin` — остановка игры.
- Роли для 4–15 игроков: Дон, Мафия, Мирные жители, Коммисар, Сержант, Доктор, Любовница, Адвокат, Камикадзе.
- Ночные действия через кнопки (callback) в ЛС, чат мафии и чат коммисара-сержанта прямо в ЛС бота.
- Логика ночи: последний ход — за доном; любовница блокирует дона/коммисара; доктор лечит (себя — 1 раз); камикадзе взрывается и забирает убийцу; адвокат маскирует проверку; единогласный голос мафии перебивает выбор дона.
- Дневное голосование 1 минута, голоса пишутся в чат, повешение с раскрытием роли.
- Победа мафии при счёте 1-на-1, победа города при уничтожении всей мафии.

## Требования

- Сообщество ВК с включёнными сообщениями.
- Публичный HTTPS URL для Callback API (ngrok, VPS и т.п.).
- Бот должен быть **администратором** беседы, чтобы получать `message_new` и отправлять кнопки.

## Установка

```powershell
cd mafia_bot
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
Copy-Item .env.example .env
```

Отредактируй `.env`:

```ini
VK_TOKEN=vk1.a....            # токен сообщества (Управление > Работа с API > Ключи доступа)
VK_CONFIRMATION=...           # строка подтверждения из настроек Callback API
VK_SECRET=...                 # секретный ключ Callback API (рекомендуется)
VK_GROUP_ID=123456789         # ID сообщества
WEBAPP_PORT=8080
CALLBACK_PATH=/               # путь для событий Callback API
```

## Запуск

1. Запусти туннель: `ngrok http 8080`
2. Запусти сервер:

```powershell
.venv\Scripts\python bot.py
```

3. В настройках сообщества: **Управление > Сообщения > Callback API**:
   - Адрес: `https://....ngrok-free.app/` (совпадает с `CALLBACK_PATH`)
   - Укажи секретный ключ (`VK_SECRET`), если задан.
   - Включи типы событий: **message_new**, **message_event**.
   - Нажми «Подтвердить» — сервер вернёт строку из `VK_CONFIRMATION`, проверка пройдёт.

## Как играть

1. Добавь бота в беседу и сделай его администратором.
2. Все игроки пишут боту в ЛС (регистрация) и ставят `/setnick`.
3. Кто-то пишет `/start` в беседе → кнопка «Присоединиться».
4. Игра стартует сама (5 минут / 15 игроков) или по `/startadmin`.
5. Ночью каждый получает в ЛС кнопки действия, утром — дневное голосование в ЛС, итоги — в беседу.

## Файлы

| Файл | Назначение |
|------|-----------|
| `bot.py` | Точка входа — aiohttp-сервер VK Callback API |
| `handlers.py` | Обработка `message_new` / `message_event` |
| `game.py` | Игровой движок: ночь, день, голосование, победа |
| `vk_api.py` | Обёртка над VK API (send/edit/кнопки) |
| `game_manager.py` | Игры, ники, регистрация (JSON) |
| `roles.py` | Роли и конфигурация ролей по количеству игроков |
| `models.py` | Да-таклассы игрока/действия |
| `keyboards.py` | VK-кнопки (callback) |
| `config.py` | Конфигурация из `.env` |
